# Cosine

- The cosine bound is
```
-1 <= cos(0) <= 1
```
- In a right triangle, cos(0) = adjacent/hypotenus.
- Hypotenuse is always the longest side, so the adjacent side can never be longer than the hypotenuse. Thus
```
adjacent/hypotenuse <= 1
```
- The negative comes from the fact that for angles between 0 and 90: 0 <= cos(0) <= 1. But hwen the angle goes past 90, cosine becomes negative.
